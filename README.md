# لُغْزَدان | LUGHZDAN

تطبيق Android أصلي بالعربية، يجمع ستة عوالم معرفية ومحركات ألعاب تعمل محلياً. فرع التوحيد يجمع تاريخ المراحل 02–07 ويعالج أخطاء البناء والحزمة الافتتاحية.

- Android 8.0+ (API 26)، حزمة Release لمعمارية `arm64-v8a`، ومعرّف ثابت `com.lughzdan.app`.
- 600 تحدٍّ نشط وصور أصلية مضمنة، مع Room لحفظ التقدم وDataStore للإعدادات.
- API محدود الصلاحيات على Neon، كتالوج PostgreSQL، حزمة موقعة Ed25519 وتنزيلات HTTPS قابلة للاستكمال والتحقق.
- اللعب المحلي متاح دون حساب. تسجيل الدخول ومزامنة الحسابات غير مهيأين في نشر هذا الإصدار؛ الواجهة توضح ذلك. لا يمثل التحقق التقني مراجعة علمية مستقلة للمحتوى.

انظر [دليل الإصدار](docs/UNIFIED_RELEASE.md) للبناء والاختبارات وحالة النشر.

## فرع تجربة الاكتشاف — قيد التحقق

يتضمن `feat/lughzdan-next-experience` تنقلًا بأربعة أقسام، وترتيب عرض ثابتًا لكل جلسة، وتحديًا يوميًا محفوظًا بتوقيت عدن، وسجلًا يُحمّل تدريجيًا، وبحثًا في المكتبة، وسحبًا للبحث عن الكلمات والترتيب مع بدائل بالنقر. هذه التغييرات ليست إصدارًا نهائيًا معتمدًا بعد.

راجع [سجل التنفيذ وحدود التحقق](docs/next-experience/STATUS.md). التصحيحات التحريرية منشورة في حزمة موقعة بإصدار جديد ومعرّفات بديلة؛ تبقى الجولات السابقة مرتبطة بمحتواها الأصلي. لتجديد التدقيق: `python scripts/audit_experience_content.py`.

### ديوان الألغاز

من الرئيسية أو مكتبتي، افتح «ديوان الألغاز» واختر «أكمل الحروف» أو «خمن الكلمة». تضم الحزمة 48 تحديًا في المفردات والأدب والبلاغة والشعر التراثي والحديث والألغاز الوصفية. تعرض بطاقة النتيجة الجواب والشرح والمصدر. تتطلب زيارة المصدر الخارجي اتصالًا، ويمكن إكمال الجولات وحفظها دون إنترنت.

حزمة الديوان مستقلة عن الحزمة الافتتاحية ذات 120 لغزًا. يتحقق التطبيق من توقيع الحزمة وبصمات ملفاتها قبل تثبيتها، ويحتفظ كل دور بمعرّف الحزمة وإصدار اللغز الذي بدأ به.


### الأطلس العربي 2.0.0 — مرشح الاختبار

ستة عوالم، و30 رحلة من خمس محطات، ومواجهة محلية للاعبين، ودفتر اكتشافات بمراجعة تفاعلية. تشمل الأنماط الجديدة «المحقق اللغوي» و«جسر الكلمات» و«من أنا؟»، مع المتقاطعة بالشبكة أو السؤال والكلمة. جميع التحديات المضمنة متاحة دون اتصال؛ لا يلزم تنزيل 40% من المحتوى للعب. السحابة قناة توسعة اختيارية عبر Neon، وليست شرطًا لفتح الجولة.

يضم الكتالوج 600 تحدٍّ نشط: الافتتاحية 120، والديوان 48، و432 تحديًا جديدًا مبنيًا على 144 فكرة، مع 32 بديلًا تصحيحيًا يحل محل عرض الأسئلة المتضررة. قد تتكرر الفكرة بصيغ مختلفة؛ هذا ليس ادعاءً بوجود 600 موضوع مستقل. تحفظ الحزم الأصلية لاستئناف الجولات القديمة.

نسخة الأطلس التجريبية تستخدم معرّف الديوان نفسه `com.lughzdan.app.preview.diwan`، وversionCode=104، وتُوقّع محليًا بمفتاح تجربة الديوان المحفوظ. لا تُحذف نسخة الديوان قبل التحديث. يبقى معرّف الإنتاج `com.lughzdan.app` ومفتاح مالكه منفصلين؛ تعذر إصدار تحديث للإنتاج لغياب مفتاحه الأصلي.

راجع [سجل تسليم الأطلس](docs/atlas/DELIVERY.md) و[منهج مراجعة المحتوى](docs/atlas/CONTENT_REVIEW.md). قياسات أداء هاتف فعلي ومراجعة علمية بشرية مستقلة ليستا نتيجتين مُنجزتين.
