# الإصدار الموحد

## أساس الدمج

الفروع الخمسة متسلسلة في تاريخ Git؛ الفرعان stage-05-06 وstage-06-07 كانا عند الالتزام نفسه 80fc312. استخدام ذلك الرأس يحتفظ بعمل المراحل السابقة دون الكتابة فوقه أو دمج نسخ مكررة.

## إصلاحات

- إصلاح وصول محرك الصور إلى مخفض الحروف وتصحيح تعريف Triple للإنجازات.
- اختبار الحزمة الفعلية في محركات Kotlin، مع تشغيل الحلول وحفظها واستعادتها. تصحيح مسارين منعطفين في البحث عن الكلمات.
- استبدال مراجع الصور التجريبية غير المطابقة برسوم أصلية قابلة لإعادة التوليد؛ حفظ الحقوق وبصمات الملفات وأبعادها.
- إصلاح أمثلة المنطق البصري لتوافق قواعد المتتاليات المثبتة، مع زيادة مراجعة الأمثلة المتغيرة.
- تفعيل قراءة الصور المضمنة للإصدار بعد مطابقة هوية الحزمة وبصمتها؛ دون تجاوز فحص SHA-256.
- ربط كتالوج الحزم بإصدار التطبيق الفعلي، وتوقيع بيانات تنزيل الحزم بمفتاح Ed25519 عام مضمن.
- جعل معرف الضيف ثابتاً في DataStore، وإزالة زر تسجيل دخول لا ينفذ شيئاً والادعاءات غير المنفذة عن المزامنة.
- استخدام npm audit بدلاً من فحص Dependency Review غير المدعوم بإعدادات هذا المستودع.

## قاعدة البيانات والخدمة

Project: `young-hall-20561827`. Release branch: `br-purple-frost-baw74zwb` / `release-unified-20261102`. Database: `lughzdan`.

ترحيلات 001–008 طُبقت على نسخة معزولة من main بعد فحص أساس المرحلة الأولى. جرى نشر 120 لغزاً و33 لعبة و6 فئات وحزمة موقعة. لم تُمسح بيانات أو فروع سابقة. فرع الإصدار مثبت لخدمة هذا الإصدار؛ لا تحذفه عند تنظيف فروع الاختبار.

الخدمة: https://br-purple-frost-baw74zwb-catalog.compute.c-8.eu-central-1.aws.neon.tech/

الحساب `lughzdan_runtime` لا يملك SUPERUSER أو BYPASSRLS أو CREATEDB أو CREATEROLE، وهو عضو في `api_catalog` فقط. كل طلب بيانات يستخدم `SET LOCAL ROLE api_catalog` في معاملة قراءة. `CATALOG_DATABASE_URL` و`PUBLIC_API_URL` متغيرات خادم؛ لا توجد بيانات اتصال PostgreSQL في APK.

`services/api/scripts/sign-opening.ts` يولد بيانات الحزمة الموقعة والبيانات العامة فقط؛ يتطلب `CONTENT_SIGNING_KEY_FILE` خارج Git. `scripts/publish_opening_sql.py` ينتج عملية النشر من الحزمة الموقعة؛ لا يعيد كتابة المراجعات المنشورة.

## البناء

JDK 17، Android SDK 36 وGradle 8.13:

```sh
cd apps/android
./gradlew :core:game-engine:test :core:content:test :app:assembleDebug :app:assembleRelease
```

لتوقيع Release عرّف `LUGHZDAN_KEYSTORE` بمسار مخزن المالك و`LUGHZDAN_STORE_PASSWORD` بكلمة مروره، alias هو `lughzdan`. لا ينشئ البناء مفتاحاً بديلاً تلقائياً. النسخة بلا هذه المتغيرات غير موقعة ولا توزع كتحديث.

```sh
cd services/api
npm ci
npm run typecheck
npm run build
npm test
```

في حاوية لا تدعم UID/الذاكرة المشتركة لـPostgres، استخدم `TEST_DATABASE_ENGINE=pglite npm test`. الفحوصات على GitHub تستخدم PostgreSQL أصلياً أيضاً. اختبارات الجهاز تعمل على API 26 و28؛ تعريف minSdk وحده لا يكفي لإثبات التشغيل.

## حدود هذا الإصدار

تسجيل الدخول ومزامنة حسابات المستخدمين غير مهيأين في نشر الخدمة الحالي، وتبقى بيانات الضيف محلية. محركات وبروتوكول المزامنة القائمة محفوظة ومختبرة، لكنها لا تمثل خدمة حسابات منشورة. بيانات المراجع الموروثة تحتاج إلى مراجعة علمية مستقلة؛ لم تُختلق أسماء مراجعين أو موافقات بشرية.
