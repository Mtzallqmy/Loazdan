# ديوان العرب · الدفعة الأولى

يضم الفهرس المحلي 60 مختارًا شعريًا و20 قطعة نثرية. لكل مختار شعري أربعة أسئلة ولكل قطعة نثرية ثلاثة. يبقى كتالوج الأطلس السابق متاحًا في مسار اللعب نفسه. تُحفظ أبيات «ديواني» ونتائج الإجابات ومواعيد تسميعها على الجهاز.

لكل مختار رابط إلى روايته. استُعين بفهرس [Ashaar](https://huggingface.co/datasets/arbml/ashaar) لتعيين النصوص الشعرية وأصحابها، وبرواية [مرثية مالك بن الريب](https://ar.wikisource.org/wiki/مرثية_مالك_بن_الريب). القطع النثرية مقتطفات من ثمانية كتب تراثية في [OpenITI](https://openiti.org/). تضم بطاقات القراءة رابط الكتاب، وفي معظم الإحالات رقم سطره. الشروح والأسئلة تعليمية أُعدّت لهذا التطبيق وتنتظر مراجعة أدبية بشرية مستقلة. تشير بطاقة أبي تمام إلى دراسة عن البردّوني وتعرض رابطها.

يستخدم الاستماع صوت الجهاز العربي المحلي عند توفره. تسجيلات الإلقاء البشري والحزم الصوتية المنزّلة تخص دفعة لاحقة. يعمل البحث والقراءة والاختبار والتسميع بلا اتصال.

يفحص `python scripts/check_diwan.py` سلامة الفهرس وتفرّد النصوص والأسئلة. يفحص `scripts/verify_release_apk.py` أن فهرس التطبيق يطابق المصدر بايتًا ببايت.
