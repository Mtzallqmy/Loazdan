# Crossword engine

CrosswordGenerator consumes editorial GeneratorWord records, dimensions, seed and total placement-attempt budget. It validates tokens, IDs, dimensions and provenance, sorts longest first, and enumerates seeded candidate placements. Subsequent words require a matching crossing. Conflicts, same-direction overlap and concealed entries reject. After placement every maximal run of at least two cells must exactly match a declared entry; all entries must be connected. Across decreases column; down increases row. GenerationResult.Success contains a complete payload, while Failure exposes a reason and never a partial layout.

The default total budget is 1000, capped at 50000. A deterministic depth-first backtracking search tries alternate placements and alternate remaining bridge words. A global node budget bounds every attempted candidate, including rejected candidates; exhausting it returns failure. No clue or source is invented. The tests run a deterministic seed corpus, validate every returned success and report measured paired generator p50/p95 with runtime environment. Those observations are not a product latency guarantee.
