# رؤية المنتج وحدود الإصدار

لُغْزَدان عالم ألعاب عربية Android API 26+؛ اللعب أصل التجربة، والتفسير القصير مكافأة معرفية بعد الحل. الهوية: لُغْزَدان | LUGHZDAN؛ حقوق المنتج المقترحة © معتز العلقمي — اليمن، تعز — 2026. المحتوى الخارجي يحتفظ بحقوق أصحابه.

جلسة 2–7 دقائق: اختر عالمًا ← لعبة ومستوى ← تفاعل حقيقي ← نتيجة وشرح ← حفظ التقدم ومعجمك. لا تسجيل إجباري ولا عقوبة على الغياب ولا إنترنت مطلوب للأساسيات. جميع الأعمار عبر ثلاث شرائح صعوبة معرفية، لا جمع تاريخ ميلاد دقيق. الوضع الافتراضي محلي بلا إعلانات أو محادثات أو لوحة ترتيب عامة.

الإصدار الأول يستخدم تسع عائلات تفاعل: crossword، wordsearch، anagram، image_guess، choice، matching، order، text_answer، sequence. تُستخدم العائلة في عدة ألعاب ذات محتوى وقواعد محددة؛ لا اختزال الكل إلى اختيار متعدد. تضم الحزمة الأساسية هدفًا تحريريًا قدره 120 لغزًا موزعة على العوالم الستة بعد الاعتماد؛ ليس عددًا متحققًا في هذه المرحلة. إن لم يعتمد المحتوى القرآني يبقى القسم «قيد المراجعة» ويمنع الإطلاق العام بوصفه مكتملًا.

حدود v1: تجربة لعب وتنزيل وحفظ ومراجعة تحريرية كاملة؛ مزامنة اختيارية. التحديات الرسمية والصدارة تفعّل فقط بعد تحقق الخادم واختبارات مكافحة إعادة الإرسال. لا تقييم إعراب حر بالذكاء الاصطناعي وقت اللعب، ولا توليد آيات، ولا بيع مكافآت أو صناديق عشوائية. حزم المعرفة والصور الثقيلة اختيارية، بلا حد منتج مصطنع لحجمها؛ تُقيد بمساحة الجهاز وأمان الملفات.

النجاح: إكمال جلسة دون شبكة؛ تقدم لا يفقد بسبب تحديث المحتوى؛ تفسير موثق بعد كل لغز معرفي؛ مستخدم يصل للعب خلال ثلاث نقرات من الرئيسية؛ تسعة تفاعلات قابلة للوصول مع قارئ الشاشة. التحليلات المجمعة opt-in، وتحديد نسب الاحتفاظ والنمو يأتي من بيانات تشغيل حقيقية لا أرقام مفترضة.
