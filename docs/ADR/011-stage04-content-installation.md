# ADR 011 — مؤشر المحتوى وسجل الاسترداد

الحالة: منفذ محليًا؛ التحقق التشغيلي جارٍ.

Room3 يضيف pack_heads وpack_members وinstall_journal وdownloads وsync_delivery وsync_accounts وsync_replica، دون حذف أو إعادة إنشاء جداول التقدم. installed_packs التاريخي يظل سجل نسخ متاحة، وليس دليل النسخة النشطة. كل استعلام بدء/فهرسة يختار العضوية النشطة. جلسات اللعب تثبت pack/version/puzzle/revision وتتحقق من عضويتها الدقيقة.

ملفات الإصدار immutable داخل filesDir/packs/versions. journal يسبق استيراد الفهرس، والملفات تتحقق ثم rename قبل معاملة تفعيل المؤشر. لا ادعاء معاملة مشتركة بين نظام الملفات وSQLite. فشل التحديث يترك المؤشر السابق؛ تلف نسخة نشطة يعزلها ويمنع الجلسات المثبتة عليها دون حذف بياناتها، ويرجع إلى السابقة الموثقة مع بقاء highWater.

الحزم الأساسية الموروثة لا تملك عضوية دقيقة لكل نسخة؛ الشبكة ترفض تحديث معرفها قبل وجود ترحيل ملكية معتمد بدل تخمين عضويتها. الحذف يمنع إزالة تبعية مستخدمة في أي نسخة محتفظ بها.

المزامنة: سجل الإيصالات المحلي يبقى، والتسليم إلى كل حساب مسجل منفصل. لا مصادقة وهمية؛ الدمج اختيار صريح. نتائج اللعب المحلي self-reported ولا تدخل تصنيفًا رسميًا. API الحالي ينفذ دفعة sync بمعاملة واحدة (فشل عارض يلغي الدفعة كلها)، ويعيد العميل الحمولة نفسها دون تغيير المعرفات.
