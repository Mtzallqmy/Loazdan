# ADR 008 — نطاق التنفيذ الفعلي للمرحلة الثانية
Accepted 2026-10-27. تعليمات المرحلة الثانية تستبدل ترتيب التنفيذ السابق: نوع choice للمفردات هو اللعبة الوحيدة المعروضة، والأنواع الأخرى غير مسجلة حتى تنفيذها. لا تغيير لعقد choice أو قواعد النقاط. المسارات الجديدة /api/v1 هي عقد التنفيذ للقراءات المحددة في المرحلة الثانية؛ بقية OpenAPI المرحلة الأولى تصميم مستقبلي غير منشور.
الوحدات الفعلية تجمع شاشات المسار الأول في feature:games بدل إنشاء وحدات فارغة. core:game-engine يحمل النماذج والتطبيع وقراءة JSON؛ لا اعتماد Android. domain منافذ التخزين. data تنفذ المعاملات، app تركيب Hilt. Java17/Gradle8.13/AGP8.13.2/Kotlin2.2.21/SDK36/min26 إصدارات مستقرة متوافقة؛ لا ادعاء أنها أحدث كل مكتبة.
حزمة debug فقط من مسودات لغوية مؤلفة ومعلّمة fixtureOnly، بلا اعتماد علمي أو نص قرآني. release لا يحتويها، ولا يسمح الإطلاق الإنتاجي قبل اعتماد المحتوى. تنزيل الحزم الخارجية والمزامنة والحسابات خارج التنفيذ الحالي. لا توقيع وهمي؛ الأساسي موثوق من APK ويتحقق SHA256، والتوقيع الخارجي بوابة المرحلة الرابعة.
