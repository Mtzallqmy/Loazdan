# ADR010 — Optional modes and compatible reader
Accepted2026-10-28. This supersedes the Stage01 blanket statement that every optional extension requires a new schemaVersion. The existing schemaVersion1 envelope and payload names remain; optional prompt/variant are an additive v1 reader extension. Existing choice JSON and saved state decode unchanged. Known game-specific variants define distinct tasks (including collecting all multi_word targets); unknown variants must be rejected, not guessed. The new bundle2 is embedded in app0.3.0/versionCode2 only, not downloaded by older applications. Any external Stage04 manifest using these variants must require minAppVersionCode≥2 and minEngineVersion≥2. No such production pack is published now. Answer/source changes still require a new puzzle revision. Future required fields or incompatible semantics require a new schema/rules version.
