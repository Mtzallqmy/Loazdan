# ADR006 — الأصل محفوظ والتطبيع للبحث/الإجابة

الحالة: معتمد في التصميم. القرار: canonical source display immutable، NFC policies versioned، لا دمج ة/ه أو ي/ى أو الهمزات عالميًا. كل بديل إجابة معتمد صراحة. النص القرآني مستورد من مصدر مرخص فقط، والمراجعة البشرية شرط نشر. البديل المرفوض: إجابات مولدة ثم تعامل كمرجع، أو اعتماد ترخيص كتاب من قدم مؤلفه. النتيجة: source registry/digest/review workflow داخل البناء، والتقدم لا يعاد تقييمه وفق revision تغيرت.
