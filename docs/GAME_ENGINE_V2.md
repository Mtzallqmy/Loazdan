# Game engine v2

The pure Kotlin core:game-engine module registers choice, crossword, wordsearch, anagram, matching and order. There are no Android, storage, clock or network dependencies. ChoicePayload retains its three original positional arguments; additional typed fields have defaults, so old choice JSON remains readable.

New board sessions use stateVersion 2. Version 1 choice sessions round-trip unchanged; both versions continue through ChoicePlugin. Other versions reject. Restore pauses active sessions and retains revision and pack pins. Repository callers validate decoded sessions against the pinned puzzle with plugin.validateSession; codec syntax validation alone does not certify progress.

Reducers receive typed actions and return immutable state. Replayed processed IDs, terminal sessions and invalid operations have no effect. Hints are charged once per hint ID. Three wrong verifications lose. Winning score is max(0, 50 + 50 × difficulty − 10 × wrong submissions − used hint penalties). Incomplete submissions are free.

Crossword cells use row,col map keys; input validates a single Unicode token. Word search SelectPath drafts a straight bounded path; Submit verifies it, locks its word ID and clears the draft, or counts an incorrect attempt. Reversed paths are accepted. Matching Match edits a draft bijection, replacing conflicts without penalty; Submit verifies only a complete draft. Order Reorder accepts only complete permutations and Submit verifies. Tile identities are inventory indices; fixed slots consume the first available matching tile per fixed token. Reserved tiles cannot be selected again. Builder Submit evaluates the fixed tokens and selected movable tokens against accepted editorial answers; subset inventory answers are permitted. Multi-word variants collect all distinct accepted targets, reset the movable selection after each success and award no completion score until every target is found. Shuffle requires an explicit seed.

Puzzle validation checks provenance, bounds, token policy, collisions, maximal crossword runs and connected entry graph, complete pair mappings, permutations, answer feasibility and declared search occurrences. Session validation checks references, derived score, terminal solution and foreign game progress. New semantic/builder modes use the same reducer per type and editorial variant labels.

HintProvider.next returns the next unused editorial hint plus a concrete unsolved board target where applicable. Looking up a suggestion is free; only UseHint records its penalty. DifficultyController.metrics reports size, crossword intersections, fixed positions and search directions. nextDifficulty uses the last five terminal records, requires at least three, raises only for entirely mistake-free unassisted wins and lowers when at least half have losses or two mistakes. It clamps to levels 1–5 and does not rewrite puzzle difficulty or score.
